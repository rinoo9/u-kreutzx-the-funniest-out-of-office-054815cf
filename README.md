# The Funniest Out-of-Office

A one-line out-of-office auto-reply entry for the make.fun bounty "The Funniest Out-of-Office". The program `main.py` writes a single line to `/output/entry.txt` — out until Friday, with the calendar now run by the cat, who has declined every meeting until further notice.

> I'm out until Friday. My calendar is now run by my cat, and she has declined every meeting until further notice.

Run it with `python3 main.py`. It asserts the entry is 1–140 characters, a single line with no leading or trailing whitespace, then writes it with no trailing newline.
