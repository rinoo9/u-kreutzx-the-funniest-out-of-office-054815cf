# The Funniest Out-of-Office

A one-line out-of-office auto-reply entry for the make.fun bounty "The Funniest Out-of-Office". The program `main.py` writes a single line to `/output/entry.txt` — away until Monday, with the inbox left in charge and doing a better job than its owner ever did.

> I'm away until Monday. I've left my inbox in charge, and frankly it's doing a better job than I ever did.

Run it with `python3 main.py`. It asserts the entry is 1–140 characters, a single line with no leading or trailing whitespace, then writes it with no trailing newline.
